## jfdevelops skills

Read each skill before the work it describes:

- [jf-coding-conventions](.agents/skills/jf-coding-conventions/SKILL.md): Apply jfdevelops coding conventions when implementing or reviewing JavaScript, TypeScript, or React code. Read before editing code; use the target project's toolchain and framework.
- [jf-docs](.agents/skills/jf-docs/SKILL.md): Orchestrate the analysis, planning, writing, editing, migration, and review of user-facing library documentation in jfdevelops projects, including guides, installation and quick-start pages, versioned docs, and docs for a new major. Read before any docs change, even when the request only says to document a feature, update a guide, or fix a link.
- [jf-docs-analyze](.agents/skills/jf-docs-analyze/SKILL.md): Analyze a library before documenting it in jfdevelops projects, covering its public API, mental model, TypeScript inference, runtime behavior, and extension points, from source at the target version. Use for the analyze stage of jf-docs work. Does not write pages.
- [jf-docs-plan](.agents/skills/jf-docs-plan/SKILL.md): Plan library documentation in jfdevelops projects by choosing each page's kind (tutorial, how-to guide, explanation, or reference), ordering the learning path, and mapping every public export to a page. Use for the plan stage of jf-docs work. Does not write pages.
- [jf-docs-review](.agents/skills/jf-docs-review/SKILL.md): Independently review user-facing library documentation in jfdevelops projects for technical correctness, documentation quality, and standards compliance, checked against source at the target version. Use for the review stage of jf-docs work or when asked to audit docs. Reports findings by default and edits only in fix mode.
- [jf-docs-standards](.agents/skills/jf-docs-standards/SKILL.md): Shared rules for user-facing library documentation in jfdevelops projects, covering docs layout, versioned directories, new-major rollover, frontmatter, headings, code and install fences, links, and docs checks. Read before any documentation work, usually through jf-docs.
- [jf-docs-write](.agents/skills/jf-docs-write/SKILL.md): Write and update user-facing library documentation in jfdevelops projects so developers understand and can use the library, with separate guidance for tutorials, how-to guides, explanations, and reference pages, and type-safe examples. Use for the write stage of jf-docs work and for fixing confirmed review findings.
- [jf-git](.agents/skills/jf-git/SKILL.md): Follow repository Git conventions before initializing history, naming or switching branches, staging changes, writing commits, or creating and updating pull requests.
- [jf-naming-conventions](.agents/skills/jf-naming-conventions/SKILL.md): Choose names for files, directories, packages, functions, types, and public APIs in jfdevelops projects. Read before adding or renaming these elements.
