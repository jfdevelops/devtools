# Documentation

Pages live under `framework/<framework>/v<major>/`, one directory per documented major. Each page is Markdown with `title`, `description` and `order` frontmatter.

`framework/javascript/` documents the core package `@jfdevelops/devtools-kit` and `framework/react/` documents `@jfdevelops/devtools-kit-react`. Both get the generated core API reference.

Never hard-wrap Markdown: write each paragraph and list item on a single line, in pages, maintainer notes, READMEs and changesets alike. The vendored skill files under `.agents/` and `.claude/` are exempt because `@jfdevelops/cli` manages them.

`maintainers/` holds design and contributor notes. They are not published and no public page links to them.

`docs.json`, every `meta.json` and the current major's `reference/` are generated by `@jfdevelops/docs` and are not committed:

```sh
docs:generate   # API reference, docs.json and meta.json
docs:check      # frontmatter, layout, links, anchors and install commands
```
